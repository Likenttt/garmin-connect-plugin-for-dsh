## 已实现范围

通过原生侧栏扩展注册成员、时间线、备注和我的训练四个 Tab；现有 Garmin 登录与工具保持原入口。客户端使用可选服务注入，复用 Host RPC，无新增账号进程或常驻 HTTP 服务。

成员列表使用现有已配置账号；状态初始为未检查，手工检查使用跳过缓存的实际 profile 请求。网络错误与需重新登录分别处理。时间线按需读取最多 100 条近期活动和对应佳明日历范围，并注明返回范围限制。

备注和本人偏好保存在本机 SQLite，按 Host 工作区和账号身份隔离，备注更新/删除使用修订号。数据库延迟打开；目录 `0700`，数据库 `0600`。凭据和原始 profile 不进入这套接口及导出。

## 修复的桌面兼容差异

Cordis 要求先注入 `loader` 才能访问该服务，原生运行时检查发现后已改为可选子上下文注入。桌面版可将 `baseUrl` 放在加载上下文而非 Loader 的可选配置字段中；数据库作用域同时支持两种来源，否则不退回共享的全局作用域。

原生 tab 的 `useTabInfo` 由框架注入；导航通过绑定会话的 `tab.actions` 执行。旧导航参数不会在重新挂载时覆盖新选择的成员。草稿按客户端会话与账号保留，保存后进入 SQLite。
