## 复现简述

1. 安装验收包，核对版本、编译文件与账号配置；用现有 session 保存只读库及日历基线。
2. 在 Harness 新会话指定大陆主账号，要求创建唯一名称的 60 秒测试课表，并排到 `2026-10-23`。
3. 核对创建预览及独立回读，确认预览未写入；用户确认后由 Agent 完成创建加排期。
4. 对返回的同一个 `workoutId` 请求排到 `2026-10-24`，核对预览并确认，由 Agent 调用独立排期工具。
5. 独立读取两天日历和单条排期详情，核对两个不同的 `scheduleId` 及同一个课表 ID。
6. 经确认后由 Agent 先取消两条指定测试排期，回读确认模板保留；再删除指定测试模板。
7. 回读确认模板 HTTP 404、列表无测试对象、日历无测试排期，并比较原库 ID 集合及账号配置。
